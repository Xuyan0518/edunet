# 附件四：数据处理和安全责任说明

1. 乙方为业务数据的主要提供方和使用方，应负责取得学生、家长、教师及其他数据主体的必要授权或同意。

2. 甲方为提供系统服务而处理业务数据，处理范围限于系统运行、技术支持、数据备份、安全维护、AI 生成、通知发送及双方确认的其他目的。

3. 双方应分别采取与其角色相适应的管理和技术措施，防止数据被未经授权访问、泄露、篡改、丢失或滥用。

4. 乙方不得上传违法违规内容，不得上传与教育管理业务无关的敏感数据，除非已取得充分合法依据并经甲方确认系统具备相应处理条件。

5. 如乙方要求将数据提供给第三方，乙方应自行确保该等提供行为合法合规，并承担相应责任。

6. 如适用法律要求双方签署单独的数据处理协议、跨境传输协议、隐私政策、家长授权书或未成年人信息处理规则，双方应另行协商签署。
